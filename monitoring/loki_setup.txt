--------------------------------------------------------------------------------
1. OVERVIEW
--------------------------------------------------------------------------------
Grafana Loki is a horizontally scalable, highly available, multi-tenant log
aggregation system inspired by Prometheus. It indexes only metadata labels rather
than full-text indexing, making it resource-efficient and fast.

This setup collects logs generated by Nomad jobs and Docker containers (such as
hello.py / hello-devops) and forwards them to Loki via Promtail or direct Docker
logging drivers.

--------------------------------------------------------------------------------
2. HOW LOKI WAS STARTED
--------------------------------------------------------------------------------

Method A: Standalone Docker Container
-------------------------------------
Run Loki on port 3100 using the official Grafana Loki image:

  $ docker run -d --name loki -p 3100:3100 grafana/loki:2.9.4

Check if Loki is running and healthy:

  $ curl -s http://localhost:3100/ready
  ready

Method B: Full Monitoring Stack with Docker Compose (Recommended)
-----------------------------------------------------------------
Using the provided `monitoring/docker-compose.yml` which deploys Loki, Promtail,
and Grafana together:

  $ cd monitoring
  $ docker-compose up -d

Verify all containers are up:
  $ docker ps
  CONTAINER ID   IMAGE                  PORTS                    NAMES
  ...            grafana/loki:2.9.4     0.0.0.0:3100->3100/tcp   loki
  ...            grafana/promtail:2.9.4                          promtail
  ...            grafana/grafana:10.3.3 0.0.0.0:3000->3000/tcp   grafana

--------------------------------------------------------------------------------
3. LOG FORWARDING SETUP (NOMAD / DOCKER -> LOKI)
--------------------------------------------------------------------------------

Option 1: Using Promtail (Included in Stack)
Promtail tails the logs from:
  - Nomad allocations: /opt/nomad/data/alloc/*/alloc/logs/*.std*
  - Docker container logs: /var/lib/docker/containers/*/*-json.log
  - System logs: /var/log/*.log

Promtail automatically attaches labels (e.g. job="hello-devops", job="nomad-allocs")
and pushes them to Loki at `http://loki:3100/loki/api/v1/push`.

Option 2: Docker Loki Logging Plugin
Install the Loki Docker driver:
  $ docker plugin install grafana/loki-docker-driver:latest --alias loki --grant-all-permissions

Run the container with Loki logging driver:
  $ docker run --log-driver=loki \
      --log-opt loki-url="http://localhost:3100/loki/api/v1/push" \
      --log-opt loki-batch-size=400 \
      hello-devops:latest

--------------------------------------------------------------------------------
4. COMMANDS TO VIEW AND QUERY LOGS
--------------------------------------------------------------------------------

Command 1: Querying Loki directly via HTTP API (cURL)
------------------------------------------------------
Query logs with LogQL using curl and jq:

  $ curl -G -s "http://localhost:3100/loki/api/v1/query_range" \
      --data-urlencode 'query={job="hello-devops"}' \
      | jq '.data.result'

Or check streams for Docker logs:
  $ curl -G -s "http://localhost:3100/loki/api/v1/query_range" \
      --data-urlencode 'query={job="docker-containers"}' \
      | jq '.data.result[].values'

Command 2: Using LogCLI (Loki CLI tool)
---------------------------------------
Install LogCLI:
  $ wget https://github.com/grafana/loki/releases/download/v2.9.4/logcli-linux-amd64.zip
  $ unzip logcli-linux-amd64.zip && sudo mv logcli-linux-amd64 /usr/local/bin/logcli

Export the Loki URL:
  $ export LOKI_ADDR=http://localhost:3100

Query logs in real-time or follow stream:
  $ logcli query '{job="hello-devops"}'
  $ logcli query --tail '{job="docker-containers"}'

Command 3: Viewing Logs in Grafana Web UI
-----------------------------------------
1. Open your browser at http://localhost:3000 (Default login: admin / admin).
2. Navigate to Connections -> Data Sources -> Add data source -> Loki.
3. Set Loki URL to: http://loki:3100 (or http://localhost:3100 if Grafana is running locally).
4. Click "Save & test".
5. Go to Explore tab -> Select Loki datasource.
6. Enter the LogQL query:
     {job="hello-devops"}
   or
     {job="nomad-allocs"} |= "Hello, DevOps!"
7. Click "Run query" to visualize the logs in real-time.
